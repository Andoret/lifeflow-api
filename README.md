# LifeFlow API 🚀

Backend for LifeFlow app — a personal assistant that helps manage expenses, workouts, and recipes.

## 🧠 Tech Stack

- NestJS
- Prisma
- PostgreSQL
- JWT Authentication

## 📦 Features

- User authentication
- Expense tracking
- Workout recommendations
- Recipe suggestions

## ⚙️ Installation

```bash
npm install

```
## 🚀 Run in Development
```bash
npm run start:dev
```
